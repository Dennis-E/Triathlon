How to export TrainingPeaks workout files

Back to dashboard

TrainingPeaks limits each Workout Files export to 12 months or less. Export each period separately, then select the resulting ZIP archives together in TriAnalytica.

  1. Sign in to TrainingPeaks in a browser.
  2. Open your account menu by clicking your name in the upper-right corner, then choose Settings.
  3. Scroll to Export Data. In the Workout Files section, enter a date range of 12 months or less and choose Export.
  4. Repeat the Workout Files export for each additional date range you need. Prefer consecutive, non-overlapping periods; TriAnalytica will merge the activities and remove duplicate workouts from overlaps.
  5. Download the resulting workout-file archive(s). If TrainingPeaks provides a folder rather than a ZIP, create a ZIP archive of that folder without changing the contained files. TriAnalytica expects the FIT/GZIP workout files and may use timestamped GPX/GZIP tracks for route maps.
  6. Return to TriAnalytica, click Import TrainingPeaks, and select all of the ZIP archives together. You can select more than one file in the file picker.

Choose Workout Files, not Workout Summary or Custom Metrics; those exports are CSVs and are not the FIT workout archives imported here. TrainingPeaks can change its menus; see its current official Data Export instructions if labels differ.

Selected workout files are processed in this browser and are not uploaded or stored by TriAnalytica. The app still makes network requests for libraries and its analysis counter; only the workout files and activity details stay local.
