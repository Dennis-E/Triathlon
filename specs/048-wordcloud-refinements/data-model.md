# Data Model: Wordcloud Sharing and Controls

The refinement reuses the existing imported activity and frequency-rank model; it adds no persisted or server-side data.

## Eligible word

| Field | Type | Source | Rules |
|---|---|---|---|
| `word` | string | Normalized tokens from existing activity titles | A token is eligible only if it contains at least two Unicode letter code points after normalization. Combining marks do not count as letters. Existing German/English function-word and missing-title exclusions continue to apply. |
| `count` | positive integer | Existing title-frequency calculation | Total occurrences across titles; unchanged by the new eligibility threshold. |
| `rank` | positive integer | Existing stable frequency ordering | Rank is recalculated from eligible terms only; excluded one-letter tokens never enter the rank list. |

## Wordcloud view state

| Field | Type | Lifetime | Rules |
|---|---|---|---|
| `displayLimit` | integer | Current page session | Slider range remains 10–100; initial value is 50. Effective list/cloud size is `min(displayLimit, eligibleWordCount)`. User changes remain when returning from another tab; existing import/data-reset behavior applies. |
| `includedWords` | map from word to boolean | Current page session / current dataset | Existing checkbox behavior is preserved. Collapsing the list does not alter inclusion or frequency. |
| `rankedListExpanded` | boolean | Current view activation | Starts `true` on initial load and each activation of the Wordcloud tab. Toggle changes responsive list layout only. |
| `renderComplete` | boolean | Current cloud render | `true` only after the current selected-word layout has completed; invalidated on slider, checkbox, or canvas-size change. Export requires the current render to be complete. |

## Shareable Wordcloud export

| Field | Type | Rules |
|---|---|---|
| `sourceTab` | fixed visualization key | Wordcloud tab only for this feature. |
| `captureTarget` | rendered visualization region | Contains the current cloud canvas only, not the ranked panel, collapsed rail, slider, or navigation. |
| `hasData` | boolean | True only when the renderer is supported, at least one word is selected, and the current layout completed successfully. |
| `title` | string | Human-readable Wordcloud visualization title, used by the existing branded square preview/download composition. |
| `filename` | string | Generated by the established visualization-export naming rules using the Wordcloud tab identity. |

The image is generated and downloaded locally using the existing preview flow. No activity title, derived term, or image is persisted by this refinement or uploaded to a service.
