# Implementation Plan: Social Export Readability Refinements

**Branch**: `075-social-export-readability` | **Date**: 2026-10-30 | **Spec**: [spec.md](./spec.md)

**Input**: Focused follow-up to Feature 074 covering export-only readability and concise copy for Workout Time, Training Calendar, Pace vs., and Personal Best views.

## Summary

Improve export-only label legibility for Workout Time axes, Training Calendar years, and Personal Best SVG labels; replace verbose Pace vs. key/value context with a concise sport/metric/encoding summary; identify PB records with a `PB:` headline and a first-to-current summary. When calendar years exceed one image's readable capacity, export a numbered series containing all years on one shared scale. Reuse Feature 074's fixed-size Canvas composition, presentation metadata, captured snapshots, and preview/download PNG pipeline. Apply family-specific styling only to export snapshots/clones and preserve live dashboard styling and all analytics.

## Technical Context

**Language/Version**: Browser JavaScript; pure export utilities remain CommonJS/browser-bridged

**Primary Dependencies**: Existing Canvas 2D, html2canvas 1.4.1, Chart.js, and Leaflet; no new dependencies

**Storage**: None; summary and generated PNG remain in browser memory

**Testing**: Root Jest under Node plus browser validation at both export sizes and 360 px display width

**Target Platform**: Static browser app; export output is fixed at 1080 × 1080 or 1080 × 1350 px

**Project Type**: Static web application with classic DOM-orchestration scripts and pure utility modules

**Performance Goals**: No new latency target. Existing capture/preview/download behavior and required-resource readiness remain unchanged.

**Constraints**: Presentation-only change; preserve selected activities, chart data, calculations, units, and local-only export. Axis/chart labels remain precise even as redundant summary prefixes are removed.

**Scale/Scope**: Four existing export families/components; a calendar may expand into a numbered multi-image series when required for readable years. No tab additions, import changes, API changes, or dashboard-wide visual redesign.
